# 🛒 Blinkit Sales Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing Blinkit grocery sales data to understand sales performance, product category trends, and outlet-level performance.

The project includes an interactive dashboard built using HTML and an Excel-based sales analysis workbook. It helps users explore key business metrics and identify useful insights through interactive filters and visualizations.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Understand sales distribution across item categories.
- Compare outlet performance by outlet type and location.
- Analyze the impact of fat content on sales.
- Explore customer ratings and item visibility.
- Present business insights through interactive dashboards.

## 📊 Dashboard Features

- Total Sales
- Total Records
- Average Sales per Record
- Average Customer Rating
- Number of Outlets
- Sales by Item Category
- Sales by Outlet Type
- Sales by Location Tier
- Fat Content Analysis
- Outlet Establishment Year Analysis
- Interactive filters to explore the data

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks the following metrics:

- **Total Sales:** Overall sales value in the dataset.
- **Total Records:** Number of records available for analysis.
- **Average Sales per Record:** Average sales value per dataset record.
- **Average Rating:** Average customer rating.
- **Total Outlets:** Number of distinct outlets.

## 🔍 Data Preparation

The dataset was prepared for analysis through:
- Handling missing item weight values.
- Standardizing fat content categories.
- Creating an outlet age field.
- Organizing data for dashboard analysis.

## 💡 Business Value

This dashboard helps explore sales patterns, compare outlet performance, and understand product category contributions. These insights can support business reporting and data-driven decision-making.

## ⚠️ Dataset Limitations

The dataset does not contain transaction dates, order IDs, customer-level information, or sales quantities. Therefore, the analysis focuses on the available product and outlet records rather than individual customer orders or time-based sales trends.
